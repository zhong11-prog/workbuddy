# 2026-07-31 工作日志

## 小七智能工作台 - 完整构建

### 项目概述
创建了一个完整的个人智能工作台应用，包含 Node.js 后端 + 纯前端 SPA + SQLite 本地数据库。

### 技术架构
- **后端**: Express + better-sqlite3 + node-cron（自动备份）
- **前端**: 单页面 HTML/CSS/JS（无框架依赖，零构建步骤）
- **数据库**: SQLite (WAL 模式，自动持久化)
- **部署**: 支持局域网多设备访问（0.0.0.0:3000）

### 实现的功能模块（13个页面）
1. 首页仪表盘 - 聚合展示待办、记账、打卡、考试倒计时、经期预测、每日一句
2. 今日计划 - 添加/编辑/勾选，支持优先级+时间段+日期回看
3. 智能记账 - 收支记录，按年月展示，根据备注智能推荐分类
4. 健身 - 运动记录+计时器，周月视图
5. 韩语陪考 - TOPIK 1-4 级词汇+语法库（80词汇+28语法），学习打卡，考试倒计时
6. 电子阅读 - 书架管理（想读/在读/已读），页数+笔记
7. 随机菜单 - 菜名列表+随机推荐，按餐别过滤
8. 家常菜谱 - 食材/步骤/标签，搜索+新增，与菜单联动
9. 待购清单 - 物品管理，优先级，勾选归档
10. 健康打卡 - 自定义打卡项，连续天数统计
11. 经期记录 - 日期记录，周期计算，预测下次+排卵期，日历视图+症状
12. 心情日记 - emoji 选择+文字，月历展示
13. 番茄专注 - 25+5钟表，白噪音选择，完成撒花

### 智能特性
- 右下角猫咪"小七"：CSS 像素风格银渐层，点击呼噜声，完成任务跳跃+爱心，长时间无操作打瞌睡，时段问候
- 灵感便签浮窗
- 饮水/休息浏览器通知提醒（45分钟间隔）
- 番茄完成撒花特效
- 响应式设计（移动端底部导航栏）

### 数据与部署
- SQLite 自动持久化
- 每天凌晨3点自动备份，保留最近7天
- 多设备通过局域网 IP 实时共享
- 已配置 macOS launchd 开机自启 plist

### 文件结构
- server.js - 后端服务器（所有 API + 数据库）
- public/index.html - 完整前端应用
- backups/ - 数据库备份目录
- com.xiaoqi.workbuddy.plist - macOS 开机自启配置
